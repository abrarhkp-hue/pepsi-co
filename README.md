# PepsiCo — Transborder Shipment Movement into Saudi Arabia

This repository contains a set of professional logistics and compliance documents for PepsiCo covering the transborder movement of shipments from **Sohar Port (Oman)**, **Khorfakkan Port (UAE)**, and **Fujairah Port (UAE)** into the **Kingdom of Saudi Arabia (KSA)**.

## Ports Covered

- **Sohar Port**, Oman (OMSOH) — Primary gateway for Eastern KSA
- **Khorfakkan Port**, UAE — High-frequency vessel services, central KSA
- **Fujairah Port**, UAE (AEJEA) — Flex/overflow route, Free Zone advantages

## Key Saudi Arabia Border Crossings

- **Batha / Al Batha** — Oman–KSA border (Sohar corridor)
- **Hili / Al Batha** — UAE–KSA border (Khorfakkan & Fujairah corridors)
